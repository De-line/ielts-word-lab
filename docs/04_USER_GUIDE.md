# IELTS Word Lab 使用指南

这是个人非商业词汇练习工具，保留原站其他备考入口。初次使用先打开“单词练习”，选择主题和组；每组20词，末组不足20词也可完成。

## 练习

在输入框输入，正确后自动进入下一词，没有提交按钮。错误可删除、移动光标或替换，不必刷新；“重试本词”清空输入但保留本次真实错误标记。“跳过本词”完成该词并进入下一词，跳过不记首次正确，也不阻止整组结束。

答案遵循词库原有大小写、空格、连字符、重音和备选拼写。暂未确认的输入法组合不计完成；主要已验收用途是Android英文键盘输入。没有答题停顿时限。

收起键盘或切应用后，点输入框或“继续输入”均可恢复。“已暂停自动跳词”表示焦点状态，不是保存失败提示。保存状态在页尾，写入很快时“正在自动保存”可能很短；看到“尚未保存/无法读取学习记录”应保留页面并备份，不要清站点数据。

初次自动发音可能受浏览器播放策略限制，可手动点“重播发音”。音频错误或等待超时提示位于重播按钮下方；即使无声也能继续答题。原词库chef音频缺失属于已知资源问题。

## 记录与推荐

“学习记录与备份”可查看最近主题/组、保存位置、继续未完成练习、已完整覆盖组数，以及各组覆盖和有效正确率。

- “本次已练”是当前会话进度；“历史已完成组”表示每个成员词都至少完成过一次，跳过也算覆盖。
- 首次正确记1，改错后正确或跳过记0；未完成不算有效结果。
- 每词每设备本地日历日只取第一个有效完成。同日重练能保留原始事件，但不会把当天先错后对洗成正确。
- 最近三日按50/30/20加权，不足三日归一化。未覆盖全组时不显示正式组率；只练弱词不会缩小组分母。
- 完整且低于80%的组可进入最多10组推荐。薄弱词按最新错误/低于80%识别；最近两个不同有效日首次正确时优先退出。

“整组练习”从原组所有词开始，“只复习薄弱词”只取当前弱词，但两者共享同一历史。弱词练完可以结束，不强制全部答对；同日重练后推荐数字不变可能正符合规则。

## 保存、恢复与转移

自动保存包括已提交前缀、词位置、错误标记和会话计数。刷新或重新进入时沿用原会话，不应重复生成完成事件。恢复依赖浏览器存储成功，不能保证系统强杀前尚未提交的最后输入。

不要同时用多个标签练习/导入。更换IP、端口、浏览器、HTTP/HTTPS都可能看不到原记录；它们不一定已丢失。跨设备没有实时同步，按[备份恢复指南](BACKUP_RECOVERY.md)手动转移。

## 当前验证范围

Redmi Note 7 Pro / Android10 / Chrome101的本轮六项验收通过。桌面Chrome和模拟窄屏另有自动测试；iOS/Safari及其他设备仍需实际验证。不要把单个设备通过理解为全部浏览器兼容。
