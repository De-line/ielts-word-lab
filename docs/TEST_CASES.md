在 TEST_REPORT 中记录执行人、日期、机型、OS、浏览器和输入法版本；不以“在手机打开了页面”代替完成以下项目。

- [ ] 进入任意主题/组；检查不足 20 词末组可完成，跳过不要求先答对。
- [ ] 错词、末尾多字符 → Backspace/Delete/移动光标/选区替换 → 改对；重试/跳过均可操作。
- [ ] 练习空格词组、连字符、大写与多拼写；检查替代拼写前缀不误标红。
- [ ] 使用英文及中文/拼音输入法；候选词尚未确认时不结算，确认后只跳一词。
- [ ] 输入中停顿 30 秒和 2 分钟，再继续；不得超时判错或卡住。
- [ ] 输入中切应用、收起键盘、切横竖屏，再点“继续输入”；检查已提交值及焦点恢复。
- [ ] 列表→首页→单词练习，至少三次；空格/方向键不被旧页面拦截。
