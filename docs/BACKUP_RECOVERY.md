# 备份、导入与数据恢复

练习时自动保存，不必每组导出。手动JSON用于定期备份、浏览器/设备迁移，以及换站点地址前保存数据。文件包含个人学习时间、结果和草稿，请保存在自己控制的位置，不提交Git、公开分享或放入public目录。

## 导出并核对

1. 在学习记录页点“导出现有备份”。
2. 在Chrome下载记录或系统Download/下载目录确认实际文件存在，大小非0；页面显示“已请求下载”不保证下载已完成。
3. 记下文件名及导出时的组进度。文件名可能同日重复，由浏览器附加编号。
4. 可以重新选该文件查看版本、完成事件条数和是否含练习位置；不勾确认，点取消验证文件可读。

正常下载文件名形如 `ielts-word-lab-backup-日期.json`。gitignore覆盖此命名、backups/及local-data/，但任意改名文件仍需自行检查；不要据此认为所有私人JSON都能自动识别。

## 恢复或转移

1. **先导出目标浏览器当前最新备份**，避免覆盖其独有记录。
2. 选来源JSON；页面先校验格式和词库身份，再显示预览。格式1、词库命名空间my-ielts.vocabulary、版本5cef573-v1必须匹配当前应用。
3. 核对文件不是较早的空备份，注意导出后是否又完成过词。导入是替换，不合并；较新记录不在旧文件中时不能直接覆盖。
4. 确需替换，勾选接受覆盖并点击确认；可先用旁边按钮下载当前备份，或取消不写入。
5. 显示导入完成后，检查组率/覆盖、最近位置及继续练习的输入值；刷新后再核对。原子事务失败会保留原存储，但遇异常仍应保留文件和页面反馈，不清数据强行重试。

备份不包含原词库/音频，使用时仍需对应应用资源可访问。不同词库版本拒绝直接导入；当前没有自动身份迁移工具，不要手改版本号绕过校验。

## 不丢历史的恢复演练

完成本轮所有答题后导出完整备份B。从导出到恢复期间不再答完/跳过任何词，也不在另一个标签练习。只改变未完成草稿位置，再导入B，检查原草稿恢复；此时没有新增完成事件会被覆盖。若又产生新完成记录，先重新导出最新B。最早空备份A只留作存档，不用于替换已有历史。

Android10/Chrome101已验证下载、系统文件选择、预览取消、覆盖确认、成功恢复和刷新保留。其他浏览器可能在下载/选择文件时有不同菜单。找不到文件、存储警告或校验失败时停止替换，记录原文；不要改系统全局设置、清站点存储或上传私人JSON到求助渠道。

## 常见情况

- **刷新拒绝连接：** 先检查本地服务是否运行、是否仍用同IP/端口。它不证明IndexedDB数据丢失；服务恢复后在原地址重试，不必先导入。
- **新网址记录为空：** 协议/主机/端口变化会切换浏览器origin；旧地址能访问时在旧地址导出，再到新地址手动导入。URL路径本身不隔离存储。
- **写入失败：** 保留页面，可导出本次内存数据。若读取原历史也失败，内存导出可能不含旧历史，不要把它当作完整备份覆盖旧文件。
- **清理浏览器/卸载/存储回收：** 无云端副本，只能从自己保存的JSON恢复。
- **长期保存：** 备份下载日期按UTC命名，日级成绩按设备本地日历，二者不必是同一天；不要仅凭文件名判定内部日期错误。
